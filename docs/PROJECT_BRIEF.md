# Project Brief

CinePulse solves the "I don't know what I want to watch, I just know the
vibe" problem: most movie search tools require you to already know a
title, but people usually start from a mood or loose description instead
("something funny and short," "a sad sci-fi movie"). It's built for casual
moviegoers who want a fast way to go from a fuzzy craving to a real,
searchable set of movies, without the app inventing recommendations that
don't actually exist. I chose to extend this project rather than start a
new one because it already had working search, favorites, and an account
system in place, so the four hours available for this capstone could go
toward the part that actually needed judgment — designing an AI feature
that stays grounded in real OMDb data instead of turning into a generic
chatbot — plus the production, testing, and documentation polish the
brief asked for.
